## 2. 我们领先的地方（已实现、可验证）

1. 体积约为 Radiant 安装包的 1/19，单文件，无 .NET/WebView 依赖。
2. 识别面最广：7 个来源 + 窗口化 3D 程序询问 + 模拟器，且用户的回答会被记住。
3. 类型识别有数据依据：Steam 玩家标签投票，而不是手写猜测；不确定时不猜，让用户选一次。
4. 撤销做得最严：真实旧值、按相反顺序、崩溃恢复、按游戏的持久改动也能完整撤销。
5. 对反作弊游戏有兜底，对笔记本有专门处理。
6. 不做任何降低安全性的改动，也不做已知的安慰剂项。
7. 每次提交都在真实 Windows 上跑全部优化项的往返测试，并卡住自身开销预算（无窗口时内存 10 MB，CI 实测）。
8. 托盘常驻：灰色待机、绿色优化中；开机自启走任务计划（最高权限），开机不弹管理员确认。

## 3. 还没做到的（如实）

| 缺口 | 影响 | 计划 |
| --- | --- | --- |
| 帧数测量（ETW） | 无法当场证明效果 | M4：订阅 DXGI/D3D9 Present 事件，按游戏 PID 计算平均帧、1% low，每局记录、前后对比 |
| 显卡驱动设置（NVIDIA 低延迟模式、电源管理「最高性能优先」等） | 这类设置对部分游戏有真实影响 | 需 NVAPI/ADLX，先调研文档与授权再做 |
| 游戏 exe 名与类型需实机核对 | 个别游戏可能识别不到或类型不准 | 内测时收集；SteamSpy 标签库覆盖 Steam 游戏 |
| 实机（独显、真实游戏）测试 | 只在虚拟机和模拟环境验证过 | 用户电脑与内测用户 |
| 代码签名 | SmartScreen 警告 | 用户负责证书 |

## 4. 刻意不做的

- 游戏内覆盖层、注入、读写游戏内存或文件：反作弊风险。
- 关闭 Defender、HVCI/VBS、防火墙、Windows 更新、Spectre 缓解：降低安全性，PC-Tuning 也不推荐。
- 「清理注册表」、关闭页面文件、关闭 CPU idle states：无益或有风险（PC-Tuning）。
- 后台请求计时器精度：Windows 10 2004 起只对调用进程生效，对游戏无效。
